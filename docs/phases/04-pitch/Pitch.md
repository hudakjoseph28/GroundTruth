# Phase 4 · Pitch

**Outcome.** The team picks one main track from a demo that already shows parcel discovery and both escrow outcomes, then records the submission around that choice.

**Read first**

- The track decision and demo timing in the [UBC brief](../../ubc/UBC-Hackathon.md)
- [Phases](../README.md) for what the earlier work proved
- The buyer story in [Problem](../../context/Problem.md)

## How to choose

Run the core journey first. Consumer Applications leads when a judge can find a real parcel, name its biggest open question, and follow the deposit. DeFi & Onchain Applications leads when the authorization rules and the on-chain outcomes stand on their own: what blocks a payout, what permits a refund, and what pays the seller. Best Use of Solana needs the program ID, the network, and both transaction links either way.

QuickNode Streams and ElevenLabs are included when their phase 3 checks passed. Using a model to write or review code does not meet the separate Grok Bot bounty.

## Demo scope

The stage cut is already timed in the UBC brief: the buyer, one sourced parcel, the disputed hold, the cleared payout, and the path to a title-company pilot. The screening video is a shorter cut of that same run, with audible ElevenLabs footage if that bounty is entered. Payment claims use the saved Devnet transactions. Staged roles and test funds are labeled.

## Acceptance checks

1. A teammate who did not build the screen can run the demo and explain why the held funds did not move.
2. The submission names one main track, Solana, and only the bounties whose requirements were met.
3. The repo, the app, and the video open for a signed-out judge, and the README lists the program ID, the network, and the sponsor configuration that shipped.

## Depends on

This phase starts when [escrow](../01-escrow/Escrow.md) and [parcel research](../02-parcel-research/ParcelResearch.md) both run, and it uses the second-device proof from [connected surfaces](../03-connect-surfaces/ConnectSurfaces.md) when that proof is ready. A missing sponsor integration narrows the bounty list. It does not block the track choice.
